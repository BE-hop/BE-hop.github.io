# 双语Hero布局与分界验收

2026-10-24。本次结果为本地预览，未提交或发布线上。

## 最终规则

- 首页保持100svh整屏；工具、项目、博客、AI情报、关于五个栏目共用适中Hero高度，桌面以最初博客的约420px为参照。
- 中英文采用相同的对齐、列结构、按钮和响应式逻辑。博客沿用原本居中标题，其余页面沿用英文原有布局；没有中文专用的居中分支。
- 中文Hero使用统一系统无衬线字体、短标题和无句末标点文案；不下载新字体。首页中文仍保留三行标题。
- Hero边界由共享高度控制，不随双语文字行数改变；首页内部分隔线固定在底部。情报页移除额外72px占位与首屏独立导航背景，滚动背景沿用全站规则。
- 原栏目图片保留，工具双图延续相同暗色框，RU-Render白色封面及邮件联系功能保持。
