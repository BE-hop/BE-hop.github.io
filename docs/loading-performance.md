# 加载、图片与缓存规范

本文件只记录现行策略。10月16–22日的事故、撤回方案与后台读数见[历史证据](history/README.md)。

## 访问与资源

2026-10-23执行用户批准的“先展示、再阅读、主动查看高清”方案，优先大陆手机和普通网络。
Jekyll直接输出标题、正文、链接、分类与分页；浏览器脚本渐进增强。字体本地加载并swap，装饰不隐藏内容。
所有公开页面统一合并基础与页面资源，各最多两份主CSS和两份主JS，按内容哈希命名。模块顺序保留；基础资源跨页复用。
语言恢复保持async；旧worker迁移在load后的idle执行，不占首屏路径。高清查看器只在点击后动态导入。
普通图片进入视口附近100px才发起请求，noscript保留完整图片；加载较慢继续等待，真实失败提供局部重试。JS不可用时标题、正文、关键链接及阅读器首图仍可见。

## 图片契约

- 母版不再次有损改写。源图、尺寸、质量和转换策略共同决定衍生URL。
- 模板用data-media-role及sizes明确用途，保留data-original-src供编辑器绑定；不改变内容YAML或编辑器可写根。
- card候选最多640px，thumbnail最多480px；低对比Hero装饰最多768px。普通内容阅读图最多1280px，详细图1920/2560px只在主动查看后请求，源图不放大。
- 320/480/640px衍生图质量72，768/1280px照片80、展板/PNG84，更高档90；参数变化须产生新指纹。
- 图片已有链接时不嵌套；普通内容图添加可直接打开的高清链接，JS可用时才增强为查看器。查看器有缩放、适合窗口、关闭、重试与原图入口。
- 阅读器默认768px预览，进入视口后最多1280px阅读图；翻页立即更新，不等待下载、不吞连续操作。只预取下一张轻量图，省流/2G不预取。放大镜默认关闭，开启后才请求高清；切页重置。
- PDF/JPG展板保留完整图面和页序。高清失败不锁定翻页，过时请求不覆盖当前页。
- 编辑器替换图片时保留源字段并清除旧srcset；已经替换的草稿不能被延迟预览覆盖。

## HTTP缓存与离线退役

目标：HTML浏览器60秒后重新验证，边缘600秒；内容哈希资源一年并immutable。sw.js、release.json等更新文件绕过缓存；发布后清理受影响HTML。
若托管暂不能提供精确60秒，先尊重已验证的源站短TTL，记录实际值；禁止以代码或文档冒充后台已应用。

**部署前置条件**：六个公开入口均不带no-store/private且具备可验证的普通HTTP缓存策略。运行`python3 scripts/check-http-cache.py`；Actions会在上传部署产物前执行该检查。

迁移代码已经准备：新访问不注册worker；新页面load后仅注销本站/sw.js注册，不动其他worker、Cache Storage或语言localStorage。
/sw.js保留退役脚本，不拦截fetch、不预热、不强制接管或刷新；自然激活时注销自己。旧页面明确点击更新时仍兼容ACTIVATE_RELEASE。
旧标签页可继续读到自然关闭。为安全迁移，本轮不自动删除已有缓存；浏览器正常存储回收或用户手动清理均不影响语言偏好。

构建至少保留最近四个版本以及近30天的哈希图片/资源。清单保留各版本时间戳，避免恢复时把所有历史资产重新标为当前。
Actions优先恢复.asset-cache，缺失时通过公开manifest恢复；恢复失败必须报告，不能声称缺失历史已补齐。已丢失的旧资源仍需单独检查。

## 当前后台事实与发布步骤

2026-10-23经用户批准，已将Public HTML - short edge cache的Browser TTL从Bypass cache改为Respect origin TTL，其他规则保持原值。六个入口HTTP缓存预检通过，实际HTML为`max-age=600`；首页和Works命中CF缓存。更新文件为DYNAMIC，缺失哈希资源404为BYPASS。浏览器60秒目标尚未应用，本轮采用已验证的源站600秒TTL。
现有三条规则、Full模式及www/wechat* Worker保留；请求来自当前开发机链路，不能代表大陆直连。

正式发布按顺序：

1. 在Cloudflare公开HTML规则中撤销Browser bypass，保留源站600秒边缘缓存。用独立请求核实浏览器缓存头、边缘HIT、更新文件绕过及缺失资源不长期缓存。
2. 执行HTTP缓存预检。可用时再安排响应头规则实现60秒浏览器TTL；以实际头部为准。
3. 本地check、browser:test及精确变更审阅通过后，fetch远端并保护论坛同步提交，取得正式发布授权。
4. 走Actions构建和门禁；部署后清理受影响HTML并验证新旧访客、资源404与版本一致性。
5. 使用大陆家庭网络和手机移动网络分别测完整下载与显示时间；仍因连接/首字节/传输停顿不达标时，再对同一构建进行托管对照，单独评估费用与切换。

Cloudflare后台操作不得改变DNS代理、SSL、微信Worker或购买计划来绕过验证。

## 质量门禁和实验条件

```bash
npm run check
npm run browser:test
python3 scripts/check-http-cache.py
python3 scripts/performance-probe.py --network-label current-route --samples 5
```

静态预算：每页gzip主CSS≤30KiB、主JS≤40KiB，各最多两份；card无超过640px候选，普通srcset无高清档，viewer不在首屏脚本中。
浏览器实验：390×844、DPR2、1.6Mbps/150ms、CPU4倍节流，独立冷上下文各5次；中位LCP≤2.5s、CLS≤0.1，LCP前发起资源的压缩传输量≤400KiB。报告首屏请求范围，不能称为全页流量。
回访、连续翻页、高清失败、无JS、双语、移动端、旧worker迁移和缓存兼容分别验证。浏览器产物在test-results，CI失败保留trace。
这些是本地实验指标；真实访客p75、INP、微信内浏览和大陆/海外实际链路必须单独实测。

## 回退

性能改动和文档整理保持可单独审阅。回退代码时同时回退图片策略与引用；兼容资源继续保留，不清空缓存来掩盖失效。
退役worker地址继续提供。若后台尚未改好，门禁阻止发布；不能临时删门禁或重新叠加超时/重载机制。
