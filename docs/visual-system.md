# 视觉与交互规范

## 当前优先级

2026-10-23：展示速度、可读性和原生操作优先。保留视觉身份，装饰保持静态。
首页保留SVG隧道、石墨Hero、森林绿与暖白内容界面、双语真实文字和四个Hero入口。
首页低透明度照片层默认隐藏以减少首屏请求，原数据字段和母版保留。
取消自动下移、视差、Scroll Stack定位与默认拟真翻页；高清图只在主动查看或开启放大镜后加载。
标题、正文和关键入口默认可见，不能以CSS或JS初始化为条件。键盘、触屏、减少动态和390px布局均须检查。

## 排版与主题

- 正文和导航使用本地Manrope，Works标题Playfair Display，AI标题Space Grotesk；font-display:swap。
- Works为暖白与森林绿，AI为石墨与冰青，保持单页强调色克制。
- 品牌正面文字保持可访问，深度装饰使用伪元素，不重复可朗读DOM文字。
- 作品集三册保留书脊、纸页前口、封面色彩及明确双行标题；阅读器固定2:1，图面不裁切或重新配对。
- 展板沿用portfolio-page-*.jpg命名，横竖按原始比例跨栏显示；源媒体保留。
- 旧动效实现和历史参照见history/agents-before-fluency.md，不能据此恢复已退役交互。

## 页面职责

index.html提供语义钩子，portfolio.css/portfolio.js负责首页与Works专属行为；showcase-system负责共享外观及导航色调。
portfolio-books负责按需阅读及立即翻页，高清查看器独立按点击加载。图片用途与预算见loading-performance.md。

关于页在1800px及以上将主栏短节排为双列，减少正文与侧栏之间的无效空白；段落仍独立限制行宽。项目页浅色Hero使用深色导航文字，首屏与滚动后均检查对比。

## 联系弹窗

共享导航桌面最右端提供“联系我 / Contact”，中英切换在其左侧；移动菜单在About之后提供入口。原生dialog采用白色卡片与遮罩，二维码完整等比显示、支持长按保存，首次打开才请求。支持关闭按钮、遮罩、Esc、焦点返回及背景滚动锁定；手机窗口可滚动。微信号、邮箱可选中并可复制，成功或失败通过双语状态提示反馈；二维码失败仍可使用文字联系方式。

联系入口沿用首页冰青与石墨色调，采用低饱和深蓝灰实心色块（#193b46）、白字与右箭头，边框#315761兼顾深浅背景；悬停为#214b58，焦点描边为#7397a2。桌面导航统一20px行高与flex垂直居中，按钮外框42px高；移动菜单沿用相同按钮。滚动状态保持白字，避免继承导航灰色文字。

中英切换容器使用flex居中和10px间距；按钮继承导航字体，统一14px字号、20px行高及20px高度，清除浏览器默认margin，避免内联基线将文字压低。语言按钮与普通导航、联系按钮中心误差不超过1px。

桌面普通导航项之间、About与语言切换之间、语言切换与联系按钮之间统一20px间距；actions不再叠加左margin，普通链接不增加水平padding。中英文模式语言入口均固定显示中文 / EN，复用全站双语属性。

## 紧凑编辑式布局

首页为 Hero＋精选实践＋阅读与连接；AI Tools 为短 Hero＋目录；Works 为短 Hero＋三册作品集入口＋项目网格。首页取消章节编号导航和逐屏内容墙，旧锚点仅保留定位作用；不得让旧 #ai-tools/#projects 装饰规则作用于兼容锚点。

展示容器两侧留白约4%，最大2160px；目录在1200px为三列、1800px为四列、2400px为五列，600–1199px两列，更窄单列。首页精选桌面三列、平板两列、手机紧凑图文单列。大屏不放大低分辨率图；段落保留约60–72字符的阅读行宽。

交互以静态筛选链接、整卡跳转、明确键盘焦点、轻量边框反馈与作品阅读为主。正文、标签、状态和入口默认可见；不依赖悬停显示核心信息。新工具实际截图必须来自隔离数据，流程图明确注明示意。

联系弹窗采用两页互斥页签，支持方向键/Home/End切换；隐藏面板不进入焦点序列。邮件页提供原姓名、邮箱、电话、类型与说明字段，支持失败重试且保留输入。共享导航容器扩展到全站，博客不再单独限制1200px。AI工具双卡使用相同高度、暗色底板、边框、图片画布及标签基线；RU-Render目录截图用白色封面底板和16px留白完整显示，母版不改；三个栏目使用保留的工作台、景观和AI研究图作为静态Hero背景。关于侧栏使用肖像相框、编号短句与社交链接卡片。

主导航五个栏目（工具、项目、博客、情报、关于）使用`.landing-hero`与唯一高度变量`--landing-hero-height: clamp(400px,46svh,440px)`，采用最初博客的适中比例；手机改用clamp(500px,62svh,560px)，保留完整内容并露出后续内容。首页例外，保留100svh整屏。固定几何隔离中英文行高差异，所有Hero从文档顶部开始，图片继续铺满。中英文标题、说明、按钮和工具预览共用同一对齐及响应式列结构；博客沿用原本的居中标题，其他页面保持英文原有布局。首页细线固定在Hero底部区域，不随文案高度移动。博客只有列表入口启用共享Hero，不影响文章和归档。情报页移除额外72px占位，导航首屏透明，滚动后与全站共享背景规则。

中文Hero采用PingFang SC／Microsoft YaHei／Noto Sans CJK SC系统字体，不新增网络字体。栏目主标题30–48px、500字重、1.35行高、0.045em字距，标题去掉句末标点并缩短；说明15px、1.85行高，最多35em行宽。首页中文标题另为38–68px，保留整屏与三行结构。中文背景与英文共用遮罩，工具Hero共用同一按钮和成对预览结构。

移动导航展开面板固定在72px共享导航下方，使用不透明#f5f3ed背景、#243a30主文字和#53665a子项文字，避免页面主题把文字改成白色；面板最大高度为100dvh减72px，可独立滚动、支持Esc关闭并恢复焦点。关于页右栏不再包含精选标签，博客页和归档保留各自标签功能。
